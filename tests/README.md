# ชุดทดสอบ FORGE

เปิดระบบจริงใน Chrome แบบไม่มีหน้าจอ (headless) ด้วยข้อมูลของระบบทดลอง (DEMO) แล้วเข้าใช้เป็นผู้ใช้แต่ละบทบาท
ทำงานแบบออฟไลน์บนสำเนาของเว็บ **ไม่ส่งข้อมูลขึ้น Google Sheets**

```
python tests/snapshot.py              # ครั้งแรก / เมื่อข้อมูล DEMO เปลี่ยน: ดึงข้อมูล DEMO มาเก็บที่ tests/data/demo.json (อ่านอย่างเดียว)
python tests/run.py                   # ทุกชุดใน tests/suites.json — ผ่านทั้งหมดได้ exit code 0
python tests/run.py floor u-demo-mc   # ชุดเดียว ผู้ใช้คนเดียว
```

| ชุด | ตรวจอะไร |
|---|---|
| `sweep` | ทุกหน้าที่ผู้ใช้เปิดได้ + BOM ทุกแท็บ, เอกสารทุกชนิด, Job Card, ประวัติรายคัน, จัดซื้อ, กล่องงาน, ทีวี, Admin — ต้องไม่มี error และไม่มีหน้าว่าง |
| `floor` | โหมดหน้างาน: เปิดเองสำหรับพนักงานผลิต, เริ่ม → หยุด (สาเหตุ) → ทำต่อ → เสร็จ, แจ้งเตือนถึงหัวหน้าผลิตและซ่อมบำรุง, ขอเบิกของ, คำย่อ |
| `pilot` | จับเวลาวัดผล: ค่าเฉลี่ย, ปุ่ม "ใส่ใน KPI" ขึ้นเมื่อครบ 3 + 3 ครั้ง, บันทึกลงเครื่อง |
| `flows` | ส่งต่องานทีละคน: ใบเบิก (ขอ → อนุมัติ → จ่าย → ยืนยันรับด้วยรหัสผ่าน + หลักฐาน), อนุมัติ PR ตามวงเงิน/แผนก, เอกสารที่รอแต่ละชนิดถึงใคร, ใครเห็นเอกสารชนิดไหน |
| `tv` | จอทีวีตามคน: จอเริ่มต้นตามหน้าที่, จอผู้บริหารต้องมีสิทธิ์, จอทีมเห็นเฉพาะแผนกตัวเอง, จอส่วนตัว |

ฝั่งเซิร์ฟเวอร์ (ไม่ต้องใช้ Google): `node tests/server-test.js` รัน `apps-script/Code.gs` จริงผ่าน `tests/gas-server.js` — เข้าระบบ/ล็อกบัญชี, ซ่อนรหัสผ่านคนอื่น, แก้สิทธิ์ได้เฉพาะ Admin, เอกสารลับ, ประวัติลบไม่ได้, หลังบ้าน ·
`python tests/live-login.py [ผู้ใช้] [รหัส]` — เข้าระบบ DEMO จริงแบบเครื่องใหม่ (ตรวจว่าเครื่องไม่มีรหัสลับหลัก/รหัสผ่านคนอื่น) ·
DEMO เปิดล็อกอินผ่านเซิร์ฟเวอร์แล้ว: `snapshot.py` ต้องตั้ง `FORGE_DEMO_KEY` = รหัสลับจากแท็บ _ตั้งค่า (B1) ของชีต DEMO ·
`python tests/secure-client.py` — เข้าระบบผ่านเซิร์ฟเวอร์ครบวงจรในเบราว์เซอร์ (รหัสผิด → ถูก → บังคับตั้งรหัสใหม่ → ออก → เข้าด้วยรหัสใหม่ → โหลดเฉพาะข้อมูลที่เปลี่ยน)

เขียนชุดใหม่: สร้าง `tests/<ชื่อ>.test.js` ที่มี `async function run(ctx)` คืนรายการข้อความ ใช้ `ctx.assert(เงื่อนไข, "ข้อความเมื่อผิด")`
แล้วเพิ่มใน `suites.json` · error ใด ๆ บนหน้าเว็บนับเป็นไม่ผ่าน · ต้องมี Chrome (ตั้ง `CHROME=<path>` ถ้าหาไม่เจอ)
