## อัปเดตล่าสุด

**30 ก.ย. 2569 — หน้าใบสั่งผลิต**
- จัดกลุ่มตามคำสั่งซื้อลูกค้า (SO) แทนคำว่า PO ที่ใช้ผิด · หัวกลุ่มบอกลูกค้า จำนวนคัน เสร็จกี่คัน เลยกำหนดกี่คัน
- คอลัมน์ใหม่ **ขั้นตอนผลิต** จาก Job Card จริง: เสร็จกี่ขั้น + ตอนนี้อยู่สถานีไหน ใครทำ หรือหยุดเพราะอะไร
- สถานะ ล่าช้า คิดจากกำหนดส่งเทียบวันนี้ (บอกว่าเลยมากี่วัน) · ค้นหาด้วยเลขเครื่อง/SO/ลูกค้าได้

**29 ก.ย. 2569 (7) — แผนการผลิตหลัก + ภาพรวมตามสิทธิ์**
- **แผนการผลิตหลัก** — ใต้แต่ละแผน (ตามคำสั่งซื้อ SO) แสดงคันจริงของคำสั่งซื้อนั้นทันที · ป้าย "จริง: n คัน · เสร็จ x" และ **⚠ ช้ากว่าแผน** เมื่อเลยช่วงประกอบหรือคันใดเลยกำหนดส่ง · ขั้นแผนที่ซ้อนกัน (จัดซื้อระหว่างประกอบ) แยกเป็น 2 แถวไม่บังกัน · ชื่อแผน/ลูกค้า/วันที่ไม่ล้นแล้ว · อธิบายแท่งสี/ลายขีด/◆ · ใบสั่งผลิตที่ไม่มีแผนแยกไว้ด้านล่าง
- **ภาพรวม** — ไม่ต้องเลือกมุมมองแล้ว: แสดงทุกส่วนที่ผู้ใช้มีสิทธิ์เปิดโดยอัตโนมัติ (ต้นทุนเฉพาะผู้มีสิทธิ์ดูต้นทุน, จัดซื้อเฉพาะผู้เปิดหน้าจัดซื้อได้ ฯลฯ) · ยังจัดเรียง/ซ่อนเองได้ และกด "กลับเป็นอัตโนมัติ" ได้ · มุมมองเก่าที่เคยเลือกไว้ถูกแทนด้วยแบบตามสิทธิ์
- ทดสอบ `tests/overview.test.js` (ชุดทดสอบทั้งหมด 19 ชุดผ่าน)

**29 ก.ย. 2569 (6) — งานคลัง + การเข้าสู่ระบบ**
- **ของนอก BOM** — คลังเพิ่มวัสดุสิ้นเปลือง / อะไหล่ซ่อมบำรุง / เครื่องมือ ได้ที่แท็บคงคลัง (รหัส ชื่อ หน่วย กลุ่ม ที่เก็บ Min Max)
- **Min / Max** — ตั้งได้ทุกรายการ · สถานะ "ถึงจุดสั่งซื้อ (Min)" / "เกิน Max" · Reorder เสนอสั่งจนถึง Max
- **เบิกทั่วไป (ไม่อ้างใบสั่งผลิต)** — ซ่อมบำรุง, วัสดุสิ้นเปลือง, เครื่องมือ, R&D, อื่น ๆ · ต้องระบุใช้ทำอะไร + แผนกที่รับค่าใช้จ่าย · อนุมัติ → จ่าย → ผู้รับยืนยัน เหมือนใบเบิกตาม BOM
- **ตรวจนับสต็อก** (เคลื่อนไหวคลัง › ตรวจนับสต็อก) — สร้างใบนับตามคลัง/ที่เก็บ/กลุ่ม หรือสุ่มนับวน · นับแบบไม่เห็นยอดในระบบ · สแกน QR นับ · พิมพ์ใบนับ · ส่งผล → หัวหน้าคลังอนุมัติ (คนนับอนุมัติเองไม่ได้, เข้ากล่องงาน) → ปรับยอดในสมุดคุมคลังเป็น Stock Entry เดียว (ยกเลิกย้อนได้)
- **Admin › 🔑 การเข้าสู่ระบบ & รหัสผ่าน** — แก้ชื่อผู้ใช้/รหัสพนักงาน/เปิด-ปิดใช้งานของทุกคนในตารางเดียว · ตั้งรหัสผ่าน (ชั่วคราวหรือถาวร) · สุ่มรหัสชั่วคราวรายคน/ทุกคนที่ยังใช้ 1234 + พิมพ์ใบแจ้งรหัส · นโยบาย: วิธีเข้าสู่ระบบ (รายชื่อ หรือรหัสพนักงาน+รหัสผ่านเท่านั้น) และความยาวรหัสผ่านขั้นต่ำ
- **ช่วงทดลองใช้: ทุกคนเข้าด้วย 1234** — ปุ่มเดียวตั้งทุกคนเป็น 1234 ไม่บังคับเปลี่ยน มีป้ายเตือน · กด "จบช่วงทดลอง" แล้วทุกคนต้องตั้งรหัสของตัวเอง
- ทดสอบ `tests/store.test.js`, `tests/logins.test.js` (ชุดทดสอบทั้งหมด 18 ชุดผ่าน)

**29 ก.ย. 2569 (5) — ลงนาม: เลือกช่องเอง + ลงนามแทน**
- หน้าลงนามแสดงครบ 3 ช่อง (ผู้จัดทำ / ผู้ตรวจสอบ / ผู้อนุมัติ) เลือกช่องเองได้ ช่องที่ลงไม่ได้บอกเหตุผล · กดช่องว่างบนใบเอกสารเพื่อลงนามช่องนั้นได้เลย
- **ลงนามแทน** — ต้องเลือกว่าแทนใคร + เหตุผล ใบเอกสารแสดง "ลงนามแทน … · เหตุผล" และบันทึกในประวัติ · หัวหน้าแผนกขึ้นไป (ที่ดูแลเอกสารชนิดนั้น) แทนผู้จัดทำ/ผู้ตรวจสอบ · ผู้จัดการโรงงาน/ผู้บริหารแทนผู้อนุมัติ · ยังต้องลงตามลำดับ และผู้จัดทำลงแทนผู้อนุมัติไม่ได้ · ปิดได้ที่ตั้งค่าแบบฟอร์ม
- ทดสอบ `tests/sign.test.js` (ชุดทดสอบทั้งหมด 16 ชุดผ่าน)

**29 ก.ย. 2569 (4) — ประวัติรายคัน: มีผู้รับผิดชอบทุกบรรทัด**
- หัวประวัติแสดง **ผู้รับผิดชอบงาน** ของใบสั่งผลิต + แถบขั้นตอนผลิต (CUT → QC) พร้อมผู้รับผิดชอบและสถานะแต่ละขั้น — ขั้นที่ยังไม่มอบหมายขึ้นเตือน
- ทุกเหตุการณ์มี 👤 ใครทำ/ใครรับผิดชอบ (ผู้ขอเบิก, คนจ่ายของ, ผู้รับของ, ช่าง, ผู้จัดทำเอกสาร)
- Job Card รวมเป็นบรรทัดเดียวต่อขั้นตอน (เริ่ม · กี่ช่วงเวลา · เสร็จ + เวลาจริงเทียบแผน) แทนบรรทัดละช่วงเวลา
- ไม่ดึงทะเบียนเครื่องคันอื่นที่อ้างใบสั่งผลิตเดียวกันมาปน

**29 ก.ย. 2569 (3) — ลำดับขั้น & การอนุมัติหลายขั้น** (Admin › 🪜 ลำดับขั้น & การอนุมัติ)
- **ระดับตำแหน่ง** ตั้งชื่อ/จำนวนระดับได้ (ค่าเริ่มต้น: พนักงาน → หัวหน้างาน → หัวหน้าแผนก → ผู้จัดการฝ่าย → ผู้จัดการโรงงาน → ผู้บริหาร) และกำหนดระดับรายคน (ไม่ตั้ง = ตามบทบาท)
- **ขั้นการอนุมัติ** ต่อชนิดเอกสาร — ใบเบิก, ใบขอซื้อ (แต่ละขั้นใส่ "เมื่อมูลค่า ≥ … บาท" ได้), เอกสารอื่นทุกชนิด หรือเฉพาะชนิด · แต่ละขั้น = ระดับขั้นต่ำ + จากแผนกเดียวกัน / สายบังคับบัญชา / ใครก็ได้ · มีตัวอย่างว่าแต่ละขั้นส่งถึงใคร
- อนุมัติตามลำดับ ขั้นละ 1 คน คนเดียวอนุมัติ 2 ขั้นไม่ได้ ผู้ขออนุมัติของตัวเองไม่ได้ · กล่องงานส่งถึงระดับที่ใกล้ที่สุดก่อน (หัวหน้า → ผู้จัดการ → ผู้บริหาร) · ปฏิเสธ = เริ่มขั้นใหม่ · ใบเบิก/ใบติดตามจัดซื้อ/ใบเอกสารแสดงลำดับขั้น ใคร เมื่อไร
- ชนิดที่ไม่ได้ตั้งขั้น ใช้วิธีเดิม (ขั้นเดียว) · ทดสอบ `tests/levels.test.js` (ชุดทดสอบทั้งหมด 15 ชุดผ่าน)

**29 ก.ย. 2569 (2) — กฎการตัดสินใจ + ของไม่พอ**
- **คนขอ ≠ คนอนุมัติ (ค่าเริ่มต้น)** — ผู้จัดทำอนุมัติ/ลงนามช่องผู้อนุมัติเอกสาร ใบเบิก ของตัวเองไม่ได้ (บริษัทเปิดให้ทำได้ที่ตั้งค่าแบบฟอร์ม) · PR ห้ามเสมอ · ระบบทดลองตั้งแบบเดียวกันแล้ว
- **เลือกวิธีกำหนดผู้อนุมัติได้** (ตั้งค่าแบบฟอร์ม › วิธีกำหนดผู้อนุมัติ) ใช้กับใบเบิก เอกสาร ช่องลงนามผู้อนุมัติ และใบขอซื้อ:
  - **ตามสิทธิ์** (ค่าเริ่มต้น) — ใครมีสิทธิ์อนุมัติเอกสารชนิดนั้นอนุมัติได้หมด (กล่องงานส่งให้คนที่เหมาะสุดก่อน เช่น PR → หัวหน้าแผนกที่ขอ)
  - **ตามแผนก** — หัวหน้า/ผู้อนุมัติของแผนกผู้ขอ (เอกสาร: หรือแผนกเจ้าของเอกสารชนิดนั้น)
  - **ตามสายบังคับบัญชา** — ผู้บังคับบัญชาของผู้ขอหรือคนที่สูงขึ้นไปในสายที่มีสิทธิ์ · ตั้งที่ Admin › ผู้ใช้ › **ผู้บังคับบัญชา** (กันการตั้งวน)
  - ทุกแบบ: ผู้จัดการโรงงาน/Admin อนุมัติได้เสมอ · ไม่มีใครเข้าเงื่อนไข → ผู้จัดการ · PR เกิน 100,000 ฿ ผู้จัดการเท่านั้น · คนขอไม่อนุมัติของตัวเอง · ใบเบิกบอกว่ารอใคร
- **ของไม่พอ** — ใบเบิกแสดงกล่อง "ของไม่พอ" (ขาดเท่าไร มีเท่าไร) · จ่ายส่วนที่มีก่อน · ปุ่ม 🛒 ขอซื้อส่วนที่ขาด (เติมรายการ/จำนวน/ใบสั่งผลิต/เลขใบเบิกให้) · ถ้ามี PR ที่กำลังมาอยู่แล้วแสดงเลขและขั้นแทน (PR เก่าที่รับของแล้วไม่นับ) · ใบเบิกรอในงานคลังจนของเข้าและผ่าน IQC แล้วจ่ายต่อ — ทดสอบครบวงจรทีละคน: คลัง → ผู้จัดการอนุมัติ → จัดซื้อขอราคา/PO/ยืนยันส่ง → คลังรับของ → QC ตรวจรับ → คลังจ่ายที่เหลือ → ช่างยืนยันรับ
- Job Card: ขั้นถัดไปเริ่มคู่ขนานได้ (หน้างานเตือน "ยังไม่ถึงคิว") ตามที่เลือก

**29 ก.ย. 2569 — จำลองพนักงานทีละคน ทีละเงื่อนไข (46 ข้อ) และแก้จุดที่พบ**
- **กฎตัดสินใจอยู่ในคำสั่งเอง ไม่ใช่แค่ซ่อนปุ่ม** — อนุมัติ/ปฏิเสธ/จ่ายของ/ปิดใบเบิก, เปลี่ยนสถานะเอกสาร (ต้องมีสิทธิ์จัดการ + ผ่าน "ใครเปลี่ยนได้" ของ Workflow), แก้เอกสารของคนอื่น, บันทึกขั้นจัดซื้อ — หน้าจอค้างหรือสคริปต์ข้ามกฎไม่ได้
- **ปฏิเสธต้องมีเหตุผล และผู้ขอได้รับแจ้ง** — ใบเบิกถูกปฏิเสธ / PR ไม่อนุมัติ ขึ้นในกล่องงานผู้ขอ ("แจ้งผล") พร้อมเหตุผลและชื่อผู้ตัดสิน 7 วัน
- **Job Card** — งานที่คนอื่นรับแล้วเป็นของเขา (หัวหน้างานทำแทน/โอนได้) · เปิดงานใหม่ได้เฉพาะหัวหน้า · บันทึกเสร็จเกินจำนวนที่สั่งไม่ได้ (ปุ่ม + ในโหมดหน้างานหยุดที่จำนวนสั่ง)
- ชุดทดสอบ `roles` (ดู tests/README.md)

**28 ก.ย. 2569 (ค่ำ) — ตรวจสิทธิ์ทีละบทบาท, หลักฐานรับ-จ่ายของ, จอทีวีตามคน, เข้าระบบผ่านเซิร์ฟเวอร์**
- **สิทธิ์น้อยที่สุดเท่าที่จำเป็น (ตรวจทุกบทบาทด้วยข้อมูลจำลอง)**
  - "เปิดเอกสารได้" ≠ "อ่านของทุกคนได้" — พนักงานที่มีสิทธิ์แค่ *แจ้ง* (ซ่อม ของเสีย ความปลอดภัย ใบเบิก งานบริการ TQ) เห็นเฉพาะเรื่องที่ตัวเองเกี่ยวข้อง
  - เอกสารที่มีราคา / ลูกค้า / คะแนนผู้ขาย (SO, RFQ, ประเมินผู้ขาย): พนักงานเห็นเฉพาะที่ตัวเองเกี่ยวข้อง เว้นแต่กลุ่มให้สิทธิ์ดู
  - หัวหน้าแผนกเห็นเอกสารของแผนกอื่นเฉพาะชนิดที่เกี่ยวกับงานตัวเอง (เช่น QC เห็นใบรับของ/ECR/WI แต่ไม่เห็นราคา) · ช่างประกอบไม่เห็นหน้าบริการลูกค้าแล้ว · หน้าเพจตามแผนก (ขาย/QC/R&D → บริการ, จัดซื้อ/คลัง → ติดตามจัดซื้อ)
  - ยังไม่ได้เข้าระบบ = ไม่เห็นเอกสารใด ๆ (รวมหน้าแนวคิด demo.html)
- **ส่งต่องานครบทุกจุด** — อนุมัติ PR: ไม่เกิน 100,000 ฿ หัวหน้าแผนกที่ขอ · เกินนั้นผู้จัดการ · คนเปิด PR อนุมัติเองไม่ได้ · แผนกไม่มีหัวหน้า → ผู้จัดการ (กฎเดียวกันทั้งปุ่มบันทึกและกล่องงาน) · สถานะที่รอแผนกอื่น ("รอ QC ตรวจ", "รออะไหล่") เข้ากล่องงาน "ส่งต่อถึงแผนก" ของแผนกนั้น · ใบเบิกจากหน้างานกลับมาให้ผู้ขอยืนยันรับ

## ความสามารถหลัก

### สำหรับผู้บริหารสูงสุด
- **สิ่งที่ต้องตัดสินใจวันนี้** — ระบบจัดอันดับเรื่องที่กระทบการส่งมอบจากทุกโมดูล พร้อมปุ่มไปแก้ไข
- **ต้นทุน & การส่งมอบรายคัน** — ต้นทุนจริงถึงวันนี้ (ค่าดำเนินการจาก Job Card + วัสดุที่เบิก), ประสิทธิภาพเวลา, มูลค่าคงคลัง, สาเหตุการหยุดงาน
- **จอทีวีผู้บริหาร** — ตัวเลขสำคัญ, ต้นทุนเทียบแผน, สาเหตุหยุดงาน 30 วัน หมุนสไลด์เอง
- **รายงาน PDF** พร้อม QR อ้างอิง ดูได้ทุกบริษัทในเครือ (สลับบริษัทได้)

### ผลิต (อ้างอิงกระบวนการมาตรฐานของ [ERPNext](https://github.com/frappe/erpnext))
- **ใบสั่งผลิต 1 คัน = 1 ใบ** พร้อม **หมายเลขเครื่อง (Serial)** และ **ประวัติรายคัน** ตั้งแต่เบิกของจนถึงบริการหลังการขาย
- **Routing + Job Card** — ขั้นตอนตัด → เชื่อม → กลึง → พ่นสี → ประกอบ → QC จับเวลาจริง, **เวลาหยุดพร้อมสาเหตุ (Downtime)**
- **สถานีงาน (Workstation) + ใบสรุปต้นทุน** ต่อใบสั่งผลิต (ค่าดำเนินการตามแผน/จริง + ค่าวัสดุ)
- **Master Schedule ตามวันที่จริง** เทียบแผนกับงานจริงรายคัน, จัดลำดับเองหรือตามวันที่

### คลังและการเบิก
- **สมุดคุมคลัง (Stock Ledger)** ทุกการเคลื่อนไหวตรวจย้อนได้, **หลายคลัง** (หลัก / WIP / สำเร็จรูป / รอตรวจ / ของเสีย)
- **Stock Entry** รับเข้า / เบิกออก / โอนย้าย / ผลิตเสร็จ / ตรวจนับ — ยกเลิกแล้วลงรายการกลับ
- **มูลค่าคลังแบบถัวเฉลี่ยเคลื่อนที่**, **จุดสั่งซื้อซ้ำ (Reorder)** → เปิด PR ทันที
- **เบิกของมาประกอบงาน** เป็นชุดประกอบย่อยหรือชิ้นย่อย, **ใบหยิบของเรียงตามที่เก็บ**, **สแกนยืนยันหยิบ**, **ผู้รับยืนยันรับของ**
- ของรับเข้ารอ IQC ในคลัง QI ผ่านแล้วค่อยเข้าคลังหลัก

### QR / บาร์โค้ด / กล้อง
- ปุ่ม 📷 สแกนด้วยกล้องมือถือ หรือเครื่องยิงบาร์โค้ด → เปิดใบสั่งผลิต รถ ชิ้นส่วน หรือเอกสารนั้นทันที
- พิมพ์ป้าย QR ติดรถ/ชิ้นส่วน · เอกสารทุกใบมี QR ที่หัวกระดาษ · ช่องกรอกรหัสในฟอร์มกดสแกนได้

### ทุกแผนก
- **งานของฉัน** — กล่องงานรวมของแต่ละคน: อนุมัติ, จ่ายของ, รับของ, ขั้นจัดซื้อ, เอกสาร, แผนงาน เรียงเรื่องด่วนก่อน
- **เอกสาร 28 ชนิด 8 แผนก** แบบฟอร์มเหมือนกระดาษ PDF/พิมพ์ได้ · **ลายเซ็นอิเล็กทรอนิกส์** (ตั้งได้ว่าคนเดียวเซ็นหลายช่อง/อนุมัติเองได้หรือไม่)
- **เลขที่เอกสารตั้งรูปแบบได้** (Naming Series รองรับปี พ.ศ.)
- **ติดตามจัดซื้อ 10 ขั้น (P2P — ปรับ/ปิดขั้นได้)**, **R&D Workbench** (โครงการ + Gantt, TQ, ECR/EO, เทียบ BOM, คลังชิ้นส่วน), **BOM หลายระดับ** + นำเข้าจาก Google Sheet, **บริการหลังการขาย & เคลม**
- **แผนงาน & Schedule** ทุกแผนก จัดลำดับเองหรือตามวันที่ · แจ้งเตือน 🔔
- **ตรวจความสอดคล้องของข้อมูลอัตโนมัติ** · **Audit Trail** ทุกการแก้ไข · สิทธิ์รายหน้า/รายเอกสาร/กลุ่มผู้ใช้
- **หลายบริษัทในระบบเดียว** ข้อมูล โลโก้ และแผนกแยกกัน

### ปรับให้เข้ากับบริษัทได้เอง (ไม่ต้องเขียนโค้ด — แนวคิดเดียวกับ ERPNext)
- **ขั้นตอนการทำงาน (Workflow)** ของเอกสารทุกชนิด งานบริการ ติดตามจัดซื้อ และ Job Card — สถานะ สี เส้นทางหลัก สถานะปิดงาน ผู้มีสิทธิ์เลื่อนสถานะ SLA ขั้นที่ไม่ใช้
- **เลขที่เอกสาร** (Naming Series) · **แบบฟอร์ม/โลโก้/ลายเซ็น** · **บริษัท/แผนก** · **กลุ่มผู้ใช้และสิทธิ์**
- ส่วนที่ระบบใช้คำนวณอัตโนมัติ (เช่น อนุมัติ → ตัดสต็อก, รับของ → IQC) ถูกล็อก 🔒 เพื่อไม่ให้ข้อมูลเพี้ยน — ปรับได้เฉพาะส่วนที่ปลอดภัย

### เข้าระบบและความปลอดภัย
- เลือกได้: **ชื่อผู้ใช้/รหัสพนักงาน + รหัสผ่าน** หรือ **เลือกจากรายชื่อ** (จัดกลุ่มตามแผนก ค้นหาได้)
- รหัสผ่านตั้งเองได้ เข้ารหัสแบบ **PBKDF2** · รหัสชั่วคราวจากผู้ดูแลต้องเปลี่ยนตอนเข้าครั้งแรก · ลายเซ็นเอกสารยืนยันด้วยรหัสผ่าน
- ทุกการเข้าระบบ/แก้ไข/เปลี่ยนรหัส บันทึกใน **Audit Log**

### สิทธิ์และข้อมูลลับ
- ช่างหน้างานเห็นเฉพาะหน้าที่ใช้ทำงาน (ไม่เห็นราคาจัดซื้อ/รายงานทั้งบริษัท)
- คำสั่งซื้อลูกค้า ใบขอราคา และผลประเมินผู้ขาย — หัวหน้าแผนกอื่นไม่เห็น · เอกสารตั้งชั้นความลับรายฉบับได้ (ทั่วไป / เฉพาะแผนก / ลับเฉพาะคน / ส่วนตัว)
- สิทธิ์ **"ดูต้นทุน"** (ราคา มูลค่าคลัง) และ **ต้นทุนระดับผู้บริหาร** (ต้นทุนรายคัน จอทีวีผู้บริหาร) แยกจากสิทธิ์ทั่วไป กำหนดผ่านกลุ่มผู้ใช้ในหน้า Admin

- ตรวจแล้วไม่ล้นจอที่ 360 / 390 / 768 / 1024 / 1366 / 1920 px · ปุ่มใหญ่บนจอสัมผัส · เมนูลัดด้านล่างบนมือถือ
